# Hoo Did It? 🦉

The Hoo family quest game, for Lucas, Ethan, Papa and Mama.

- App: https://cjteoh-creator.github.io/hoo-did-it/
- Data: Firebase project `hoo-did-it` (Firestore + anonymous sign-in)
- Security rules: see `firestore.rules`. Paste them into Firebase → Firestore → Rules → Publish.
- Demo/test mode with no real data: add `?demo` to the URL.
